# Pengembangan Tailpiece Heater untuk Mencegah Pertumbuhan Biofilm pada Sistem Pipa Wastafel

## 1. Deskripsi Proyek
Proyek ini bertujuan mengembangkan sistem *tailpiece heater* yang dirancang untuk memberikan pemanasan pada bagian pipa pembuangan wastafel sebagai upaya menghambat pertumbuhan biofilm. Pengembangan meliputi perancangan sistem, pemilihan komponen, penyusunan prosedur kerja, dan perencanaan pengujian kinerja.

## 2. Tujuan
1. Merancang sistem *tailpiece heater* yang sesuai untuk pemasangan pada sistem pipa wastafel.
2. Mengevaluasi karakteristik pemanasan berdasarkan suhu, waktu pemanasan, dan konsumsi daya.
3. Menyusun metode evaluasi untuk mengetahui pengaruh perlakuan pemanasan terhadap pertumbuhan biofilm.

## 3. Dokumentasi Proyek
- `docs/`: studi literatur, spesifikasi, dan prosedur kerja.
- `design/`: sketsa mekanik, diagram sistem, dan rancangan rangkaian.
- `data/`: data pengujian dan dokumentasi pengukuran.
- `src/`: kode program, apabila menggunakan sistem kendali.
- `testing/`: rencana dan dokumentasi pengujian.
- `project-management/`: jadwal dan pembagian tugas.

## 4. Parameter Evaluasi
- Suhu pada bagian pipa yang dipanaskan.
- Waktu yang diperlukan untuk mencapai suhu target.
- Konsumsi daya listrik.
- Perubahan indikator pertumbuhan biofilm berdasarkan metode pengujian yang ditetapkan.

## 5. Status Proyek
Status pengerjaan setiap bagian akan diperbarui sesuai dengan progres aktual. Hasil pengujian hanya akan dicantumkan setelah pengujian dilaksanakan dan data diperoleh.

## 6. Luaran
Dokumentasi rancangan alat, prosedur pengujian, data pengukuran, evaluasi kinerja, dan rencana pengembangan lebih lanjut.
